# История изменений (Changelog)

Все заметные изменения в проекте BT Controller документируются в этом файле.

---

## [1.0.2] - 2026-11-04

### Добавлено
- **Окно «О приложении» (`AboutDialog`)**:
  - Отображение текущей версии приложения.
  - Информация о разработчике (**PasturTheFox**).
  - Интерактивная кликабельная ссылка на репозиторий GitHub с быстрым переходом в браузер.
  - Индикатор и баннер доступности нового обновления.
  - Встроенная кнопка проверки обновлений.
- Новые векторные иконки:
  - `ic_info` — иконка информации для шапки и диалога.
  - `ic_open_in_new` — иконка перехода по внешней ссылке.

### Изменено
- Кнопка принудительной проверки обновлений в верхней панели (`TopAppBar`) заменена на кнопку открытия окна «О приложении» (с сохранением индикатора доступного обновления).
- Нижняя плашка версии в списке устройств теперь также открывает окно «О приложении».

---

## [1.0.1] - 2026-11-03

### Добавлено
- Система автоматического обновления приложения напрямую из GitHub Releases:
  - Проверка новых версий по GitHub API.
  - Диалоговое окно обновления с описанием изменений (Changelog) и размером APK.
  - Фоновая загрузка файла обновления с отображением прогресса.
  - Автоматическая установка APK через Android `FileProvider` и `ACTION_INSTALL_PACKAGE`.
  - Возможность пропуска версий или откладывания обновления.

---

## [1.0.0] - 2026-11-03

### Добавлено
- Начальный стабильный релиз BT Controller.
- Виджет для домашнего экрана Android (AppWidget) с поддержкой быстрого переключения подключения Bluetooth-устройств.
- Главный экран приложения на Jetpack Compose Material 3:
  - Управление списком устройств в виджете (добавление, удаление, изменение порядка перетаскиванием).
  - Список сопряженных устройств телефона.
  - Сканирование и сопряжение новых Bluetooth-устройств.
- Поддержка профилей Bluetooth A2DP, Headset и HID.
- Поддержка Android 8.0+ (API 26–36) с адаптивными разрешениями (`BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN`).
