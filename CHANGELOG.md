# История изменений (Changelog)

Все заметные изменения в проекте BT Controller документируются в этом файле.

---

## [1.1.1] - 2026-11-25

### Добавлено
- **Единый кроссплатформенный релиз `v1.1.1`** (Android APK + Windows 11 Single-Project MSIX):
  - Автоматическая сборка и публикация подписанного MSIX-пакета `BTController-Windows-x64.msix` (и сертификата `.cer` при наличии) в GitHub Releases.
  - Синхронизированы версии Android (`versionCode 5`, `versionName 1.1.1`) и Windows (`1.1.1.0`) для корректной работы автообновления и единых ссылок загрузки.

### Исправлено
- **Виджет Windows 11 (`Win + W` / Widgets Board)**:
  - Исправлена схема расширения `Package.appxmanifest` (`Name="com.microsoft.windows.widgets"`, `PublicFolder="Assets"`, `Arguments="-RegisterProcessAsComServer"`, корректная структура `<Capability><Size Name="..." /></Capability>` и `IsCustomizable="true"`).
  - Реализован внепроцессный COM-сервер (`ComServer.cs`, `IClassFactory`, `CoRegisterClassObject`, headless-режим в `Program.cs` с `STAThread`/MTA-безопасностью) для активации `BluetoothWidgetProvider` через `Win + W`.
  - Исправлен жизненный цикл виджета (`GetWidgetInfos()` восстановление при перезапуске, `Deactivate`, потокобезопасность `ActiveWidgets`, перезагрузка настроек в `WidgetPreferencesService`).
  - Переход на **Single-Project MSIX** (`WindowsPackageType=MSIX`) с корректным копированием шаблонов Adaptive Cards (`Templates/*.json`) в пакет.

---

## [1.1.0] - 2026-11-22

### Добавлено
- Начальная версия клиента для **Windows 11** на базе WinUI 3 (`BTController.App`, `BTController.Widgets`, `BTController.Core`).
- Поддержка управления Bluetooth-устройствами через WinRT API и задел для виджета `Win + W` *(обнаружение виджета в Windows Widgets Board исправлено в `1.1.1`)*.

---

## [1.0.3] - 2026-11-17

### Добавлено
- Возможность включения/выключения автоматической проверки обновлений при запуске приложения:
  - Интерактивный переключатель в карточке версии на главном экране.
  - Настройка с описанием в окне «О приложении» (`AboutDialog`).
  - Реактивное сохранение состояния настройки в `SharedPreferences`.

### Изменено
- Фоновая автоматическая проверка при старте приложения теперь работает бесшумно и не отображает модальные диалоги, если приложение актуально или возникла ошибка сети.
- Модальное окно обновления (`UpdateDialog`) открывается при старте только при наличии нового доступного релиза.

---

## [1.0.2] - 2026-11-04

### Добавлено
- **Окно «О приложении» (`AboutDialog`)**:
  - Отображение текущей версии приложения.
  - Информация о разработчике (**PasturTheFox**).
  - Интерактивная кликабельная ссылка на репозиторий GitHub с быстрым переходом в браузер.
  - Индикатор и баннер доступности нового обновления.
  - Встроенная кнопка проверки обновлений.
- Новые векторные иконки:
  - `ic_info` — иконка информации для шапки и диалога.
  - `ic_open_in_new` — иконка перехода по внешней ссылке.

### Изменено
- Кнопка принудительной проверки обновлений в верхней панели (`TopAppBar`) заменена на кнопку открытия окна «О приложении» (с сохранением индикатора доступного обновления).
- Нижняя плашка версии в списке устройств теперь также открывает окно «О приложении».

---

## [1.0.1] - 2026-11-03

### Добавлено
- Система автоматического обновления приложения напрямую из GitHub Releases:
  - Проверка новых версий по GitHub API.
  - Диалоговое окно обновления с описанием изменений (Changelog) и размером APK.
  - Фоновая загрузка файла обновления с отображением прогресса.
  - Автоматическая установка APK через Android `FileProvider` и `ACTION_INSTALL_PACKAGE`.
  - Возможность пропуска версий или откладывания обновления.

---

## [1.0.0] - 2026-11-03

### Добавлено
- Начальный стабильный релиз BT Controller.
- Виджет для домашнего экрана Android (AppWidget) с поддержкой быстрого переключения подключения Bluetooth-устройств.
- Главный экран приложения на Jetpack Compose Material 3:
  - Управление списком устройств в виджете (добавление, удаление, изменение порядка перетаскиванием).
  - Список сопряженных устройств телефона.
  - Сканирование и сопряжение новых Bluetooth-устройств.
- Поддержка профилей Bluetooth A2DP, Headset и HID.
- Поддержка Android 8.0+ (API 26–36) с адаптивными разрешениями (`BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN`).
